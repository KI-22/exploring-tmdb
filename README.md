## TMDB API Key

To run this application, you will need these following these steps to gain a TMDB API key:
1) sign in / create an account on [TMDB](https://www.themoviedb.org/?language=en-GB)
2) ...request key...
3) ...receive key (email?)...
4) in the application, create an empty `.env` file and paste the below code in, with your own API key (where it says 'your_api_key')

`REACT_APP_API_KEY=your_api_key`

5) ENSURE that `.env` is listed on yout `.gitignore` file to avoid accidentally pushing your key to GitHub
